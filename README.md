# LUCKY DRAW

메이플스토리 월드 크리에이터 행사용 럭키드로우입니다. 참가자가 한꺼번에 떨어져 내려가고, 구간마다 먼저 포탈에 들어간 사람만 살아남습니다. 마지막 판에서 당첨자가 정해집니다.

**바로 실행:** https://sukyonghyun-sudo.github.io/lucky-draw/

## 쓰는 법

1. 「참가자 명단」에 이름을 넣습니다. 엑셀(.xlsx) · CSV · 메모장(.txt) 파일을 「불러오기」로 열거나 화면에 끌어다 놓아도 됩니다. 비워 두면 1번, 2번… 번호로 진행합니다.
2. 당첨 인원, 판 수, 코스 길이, 맵을 고릅니다.
3. START 를 누릅니다(또는 Enter).

| 키 | 하는 일 |
|---|---|
| Enter | 시작 |
| Space | 잠깐 멈춤 |
| → (누르고 있기) | 빨리 감기 |
| F | 전체 화면 |
| M | 소리 끄기·켜기 |

명단·설정·당첨 기록은 이 브라우저에 자동 저장됩니다.

## 인터넷 없이 쓰기

`index.html` 한 파일에 그림·소리·글꼴이 모두 들어 있습니다. 내려받아 두 번 누르면 인터넷 없이도 열립니다.
